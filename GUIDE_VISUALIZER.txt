================================================================
ETAPE 0 : COMPRENDRE CE QU'ON DESSINE
================================================================

Avant tout code, mets des mots sur le probleme. On a deux choses :

1) LE DECOR (statique, dessine UNE fois) :
   - des zones (les "nodes" du graph) : un rond a une position (x, y),
     avec une couleur, un nom, et parfois un role (start / end).
   - des connexions (les "edges") : un trait entre deux zones.

2) LES DRONES (dynamique, redessine A CHAQUE TOUR) :
   - a chaque tour on sait ou est chaque drone.
   - on dessine un point noir sur chaque zone occupee, avec le NOMBRE
     de drones dessus ecrit dedans.

D'ou viennent les donnees ? De deux objets que ton code produit deja :

   graph   -> objet Graph (dans utils/graph.py)
              graph.nodes : dict {nom_zone: Node}
                 Node a : .coord (x, y), .color, .name, .start, .end,
                          .max_drones
              graph.edges : dict {nom_zone: [Edge, ...]}
                 Edge a : .dst (nom de la zone d'arrivee)

   history -> une liste. UN element = UN tour de simulation.
              Chaque tour est lui-meme une liste de drones, ou chaque
              drone est un tuple :
                 (id_drone, (x, y), livre?)
              Exemple d'un tour avec 2 drones :
                 [ (1, (3.0, 5.0), False),
                   (2, (0.0, 0.0), True) ]

Le "type" qu'on ecrit en haut du fichier resume ca :

   Frame = list[tuple[int, tuple[float, float], bool]]

   Frame  = "un tour"
   int    = id du drone
   (x, y) = ou il est
   bool   = est-il arrive a la fin (livre) ?

ETAPE 3 : DESSINER TOUT LE DECOR (methode _draw_network)
================================================================

IDEE
    On generalise l'etape 2 : au lieu d'un rond invente, on boucle sur
    TOUS les nodes du graph. Et avant les ronds, on trace les traits
    (connexions), pour que les traits passent DERRIERE les ronds.

    Ordre de dessin = ordre d'empilement. On dessine :
        1. les traits (connexions)
        2. les ronds (zones)
        3. les noms
    Pour forcer l'ordre proprement, matplotlib a "zorder" : plus
    zorder est grand, plus c'est AU-DESSUS. traits zorder=1,
    ronds zorder=2, noms zorder=6.

    PIEGE des connexions : dans graph.edges, une connexion A-B apparait
    DEUX fois (A->B et B->A). Si tu traces betement, tu dessines chaque
    trait deux fois. Pour eviter : on garde un ensemble "deja dessine"
    en utilisant frozenset({A, B}) comme cle (un frozenset ignore
    l'ordre : frozenset({A,B}) == frozenset({B,A})).

A FAIRE
    Ecris une methode _draw_network(self, ax) :

    D'ABORD les traits :
        drawn = set()                       # connexions deja tracees
        pour name, edges dans self.graph.edges.items():
            si name pas dans self.graph.nodes: continue   # zone bloquee
            x0, y0 = self.graph.nodes[name].coord
            pour edge dans edges:
                si edge.dst pas dans self.graph.nodes: continue
                key = frozenset((name, edge.dst))
                si key dans drawn: continue      # deja fait, on saute
                drawn.add(key)
                x1, y1 = self.graph.nodes[edge.dst].coord
                ax.plot([x0, x1], [y0, y1], color="#ccd1d9",
                        lw=1.4, zorder=1)

        Note : ax.plot([x0,x1],[y0,y1]) trace une LIGNE entre les deux
        points. On lui donne la liste des X puis la liste des Y.

    ENSUITE les ronds + noms :
        pour name, node dans self.graph.nodes.items():
            x, y = node.coord
            ax.scatter(x, y, s=680, color=<couleur du node>,
                       edgecolors=<couleur bordure>, linewidths=<...>,
                       zorder=2)
            ax.annotate(name, (x, y), xytext=(0, 14),
                        textcoords="offset points", fontsize=6.5,
                        ha="center", va="bottom", zorder=6)

    Pour l'instant mets couleur = "#cccccc" et bordure = "black" en
    dur ; on gere les couleurs proprement a l'etape 4.

    Appelle-la dans render() apres avoir cree ax :
        self._draw_network(ax)
        ax.set_aspect("equal")   # 1 unite X = 1 unite Y (pas deforme)

ETAPE 4 : LES COULEURS ET LES ROLES (start / end)
================================================================

IDEE
    Une zone a une couleur venant de la map (node.color). Mais parfois
    cette couleur est "none" ou un truc que matplotlib ne sait pas
    afficher. Il faut une couleur de secours (default). Et start / end
    doivent rester reperables : on leur met une BORDURE de couleur
    speciale (verte pour start, rouge pour end).

    Deux petites fonctions pures, faciles a tester :

A FAIRE
    En haut de la classe, des constantes (plus propre que des valeurs
    en dur eparpillees) :
        DEFAULT_COLOR = "#cccccc"
        START_EDGE = "#1e8449"   # vert
        END_EDGE   = "#922b21"   # rouge

    Methode couleur de remplissage :
        import matplotlib.colors as mcolors  # en haut du fichier

        def _node_color(self, node):
            color = node.color
            si color existe ET color.lower() != "none"
                        ET mcolors.is_color_like(color):
                return color
            return self.DEFAULT_COLOR

        mcolors.is_color_like("red") -> True
        mcolors.is_color_like("pouet") -> False
        C'est ca qui evite un crash si la map a une couleur bidon.

    Methode bordure selon le role :
        def _border(self, node):
            si node.start: return (self.START_EDGE, 2.4)
            si node.end:   return (self.END_EDGE, 2.4)
            return ("black", 1.1)
        (elle renvoie un couple (couleur, epaisseur))

    Branche-les dans _draw_network :
        edge_color, edge_width = self._border(node)
        ax.scatter(x, y, s=680, color=self._node_color(node),
                   edgecolors=edge_color, linewidths=edge_width,
                   zorder=2)

CHECK 4
    Relance sur une map ou start et end sont connus. La zone start doit
    avoir une bordure verte epaisse, end une bordure rouge epaisse, les
    autres une fine bordure noire. Mets expres une couleur bidon dans
    une map -> la zone doit devenir grise (default) sans crash.

ETAPE 5 : COMPRENDRE L'ANIMATION (le coeur du truc)
================================================================

IDEE
    Jusqu'ici : image fixe. Maintenant on veut BOUGER. matplotlib
    anime avec FuncAnimation :

        from matplotlib.animation import FuncAnimation
        anim = FuncAnimation(fig, fonction_par_tour,
                             frames=nombre_de_tours,
                             interval=ms_entre_tours)

    Comment ca marche, en clair :
      - FuncAnimation appelle "fonction_par_tour" avec idx = 0, puis 1,
        puis 2, ... jusqu'a frames-1.
      - A chaque appel, TOI tu redessines la couche des drones pour le
        tour idx.
      - "interval" = temps d'attente entre deux appels (en ms). 800 ms
        = un tour toutes les 0.8 s.

    Probleme a resoudre : a chaque tour il faut EFFACER les drones du
    tour precedent avant de dessiner les nouveaux, sinon ils
    s'accumulent. Solution : on garde la liste des objets dessines
    ("dynamic") ; au debut de chaque tour on fait art.remove() sur
    chacun, on vide la liste, puis on redessine.

    IMPORTANT : le DECOR (etapes 3-4) est dessine UNE fois, hors de la
    fonction animee. Seule la couche drones est redessinee. C'est ca
    qui rend l'animation fluide et logique.

ETAPE 6 : DESSINER LES DRONES D'UN TOUR (methode _update)
================================================================

IDEE
    Pour un tour donne (idx), self.history[idx] est la liste des drones
    avec leur position. Plusieurs drones peuvent etre sur la MEME zone.
    On ne dessine pas 5 points l'un sur l'autre : on dessine UN point
    par zone occupee, avec le NOMBRE de drones ecrit dedans.

    Donc : compter combien de drones par coordonnee, puis un point +
    un chiffre par coordonnee.

A FAIRE
    def _update(self, ax, dynamic, idx):
        # 1. effacer les drones du tour precedent
        pour art dans dynamic:
            art.remove()
        dynamic.clear()

        # 2. compter les drones par position
        counts = {}
        pour (_id, coord, _livre) dans self.history[idx]:
            counts[coord] = counts.get(coord, 0) + 1

        # 3. dessiner un point + un chiffre par position occupee
        pour (x, y), nb dans counts.items():
            marker = ax.scatter(x, y, s=300, color="#111111",
                                edgecolors="white", linewidths=1.0,
                                zorder=4)
            label = ax.annotate(str(nb), (x, y), color="white",
                                fontsize=8, ha="center", va="center",
                                fontweight="bold", zorder=5)
            dynamic.extend([marker, label])   # on les MEMORISE pour
                                              # pouvoir les effacer

        # 4. un titre qui donne l'avancement
        livres = somme des drones ou livre? == True dans history[idx]
        total  = len(self.history[0])   # nb de drones au depart
        ax.set_title(f"Turn {idx}/{len(self.history)-1}   "
                     f"delivered: {livres}/{total}")
        return dynamic

    Note zorder : drones (4,5) > decor (1,2) -> les drones passent
    AU-DESSUS de la carte. Logique.

ETAPE 7 : LANCER L'ANIMATION DANS render()
================================================================

IDEE
    On relie tout : decor une fois, puis FuncAnimation qui appelle
    _update pour chaque tour.

A FAIRE
    Reecris render() comme ca :

        def render(self):
            si self.history est vide: return   # rien a animer

            fig, ax = plt.subplots(figsize=(13, 8))
            self._draw_network(ax)             # decor : UNE fois
            ax.set_aspect("equal")
            ax.axis("off")

            dynamic = []                       # objets drones a effacer
            anim = FuncAnimation(
                fig,
                lambda idx: self._update(ax, dynamic, idx),
                frames=len(self.history),
                interval=self.interval,
                blit=False,        # simple et robuste ; ne t'embete
                                   # pas avec blit=True au debut
                repeat=False)      # on ne boucle pas a l'infini
            plt.show()

    Le "lambda idx: self._update(...)" est juste une mini-fonction :
    FuncAnimation lui passe idx, elle appelle ton _update avec le bon
    ax et la bonne liste dynamic.

    ATTENTION : garde une reference a "anim" (la variable locale
    suffit tant que render ne rend pas la main avant plt.show()). Si tu
    ne gardes pas anim, Python peut le supprimer et l'animation ne
    tourne pas. C'est LE piege classique de FuncAnimation.

8.1 LEGENDE
    IDEE : expliquer les codes couleur (start vert, end rouge, gris =
    couleur inconnue). matplotlib fabrique une legende a partir d'objets
    "Line2D" bidons qui servent juste d'echantillons.

    def _legend_handles(self):
        from matplotlib.lines import Line2D
        return [
          Line2D([0],[0], marker="o", color="white", label="start",
                 markerfacecolor="white", markeredgecolor=self.START_EDGE,
                 markeredgewidth=2.4, markersize=11),
          ... pareil pour "end" avec END_EDGE ...
          ... pareil pour "couleur inconnue -> default" avec
              markerfacecolor=self.DEFAULT_COLOR ...
        ]

    Dans render(), apres _draw_network :
        fig.legend(handles=self._legend_handles(), loc="lower center",
                   ncol=3, fontsize=9)

8.2 SAUVEGARDE (gif ou video)
    IDEE : au lieu d'ouvrir une fenetre, ecrire un fichier. Utile pour
    la correction / le README.
        - un chemin ".gif" -> writer Pillow
        - autre extension (.mp4) -> writer ffmpeg (necessite ffmpeg
          installe sur la machine)
        - quand on sauvegarde, il faut basculer matplotlib en mode
          "sans fenetre" AVANT de creer la figure :
              matplotlib.use("Agg")

    Signature : def render(self, save_path=None)
        si save_path:
            matplotlib.use("Agg")
        ... on cree fig, decor, anim comme avant ...
        fps = max(1, round(1000 / self.interval))   # tours par seconde
        si save_path finit par ".gif":
            anim.save(save_path, writer=PillowWriter(fps=fps))
            plt.close(fig)
        sinon si save_path:
            anim.save(save_path, writer=FFMpegWriter(fps=fps))
            plt.close(fig)
        sinon:
            plt.show()

    Imports en plus :
        from matplotlib.animation import (FuncAnimation, PillowWriter,
                                          FFMpegWriter)

    (Detail confort, optionnel : en mode fenetre tu peux programmer une
     fermeture auto avec fig.canvas.new_timer(...) apres la fin de
     l'anim ; regarde le code de reference si tu veux ce comportement.)
